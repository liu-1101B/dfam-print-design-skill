# DfAM 几何配方

每个配方三段：**何时用 / 怎么建 / 建错的后果**。所有数值按 FDM 0.4 喷嘴、0.2 层高、PETG 给；其他工艺按 `process-profiles.md` 换算。

建模顺序永远是：**定姿态 → 定过渡 → 定结构 → 去支撑 → 加细节**。反过来做，细节会全部作废。

---

## 1. 45° 过渡族（最常用，先掌握这个）

**何时用**：任何"竖直面 ↔ 水平面"的转折，任何台阶的根部/顶部，任何想避免支撑的边。

**怎么建**：把转折处的直角替换成一段与水平成 45° 的直平面。需要更柔和时用两段 22.5°，不要用一整段圆弧。

```
顶边（对）            底边（对，顺便治大象脚）        台阶（对）
   ┌────╲                  ╱──────┐                    ┌───┐
   │     ╲                ╱       │                 ┌──┘   └╲
   │      ╲              ╱        │                 │       ╲
```

**数值**：倒角边长 0.5–2 mm 覆盖绝大多数场合；底边取 0.5–1.0 mm。
**失效模式**：倒角 <30° 就变成悬垂，反而要支撑；倒角太大浪费行程、且尖角处易崩。

> 记住：**45° 倒角不消除层纹**，它把宽台阶换成等宽细台阶（视觉上从"棱"变"斜纹"）。真无层纹靠后处理。

---

## 2. 圆角放哪儿：XY 可以，Z 不行

**何时用**：想做"柔和""不割手""抗应力集中"的造型时。

**怎么建**：
- ✅ **绕 Z 轴的圆角**（俯视图里的圆角/弧线）——喷嘴在 XY 连续走线，天然光滑，且不产生悬垂。
- ❌ **竖直方向的圆角**（侧视图里从底到顶的圆弧过渡）——每层都是不同半径的悬垂，层纹呈不规则带状，最难补救。

```
侧视图（错：竖直弧）        俯视图（对：绕 Z 圆角）
   ╭──────╮                      ╭────────╮
  ╱        ╲   ← 每层半径都变     │        │   ← 走线连续
 ╱          ╲                    ╰────────╯
```

**数值**：绕 Z 的圆角 R0.5–5 任意；结构件根部 R ≥ 0.5×壁厚。
**失效模式**：竖直弧 + 大半径 = 全件最丑的地方，且切片器会补一堆变宽/变窄的线，强度也掉。

**例外**：承力件的根部确实需要圆角来分散应力——这时用"XY 圆角（受力平面内）+ Z 向 45° 台阶"的组合，而不是竖直圆弧。

## 3. 泪滴孔（水平孔的唯一正解）

**何时用**：孔的轴线**水平**（垂直于 Z），且孔径 ≥3 mm。

**怎么建**：以孔心为原点、半径 r，保留下半圆，上半部换成两条 45° 直线，交于顶点 (0, r√2)。切点在 (±r/√2, r/√2)。

```
      ╱╲        apex (0, 1.414r)
     ╱  ╲
    ╱    ╲      45° 直线，自支撑
   │      │
    ╲    ╱      r
     ╲__╱       下半圆
```

**数值**：总高 2.414r，宽 2r；顶点朝上（打印方向）。
**失效模式**：直接开正圆 → 顶部 45° 以上无支撑，塌成椭圆并挂料；孔内配合面全部失效。

**变体**：装配空间允许时用**菱形孔**（旋转 45° 的正方形/六边形），四条下边都是 45°，自支撑且比泪滴短；代价是尖角应力集中，密封/受压场合仍用泪滴。

---

## 4. 桥接与锚固

**何时用**：必须有水平跨度时（槽口、把手、卡箍）。

**怎么建**：桥接的**两端都要落在实体上**，中间不要有自由端；跨度方向尽量垂直于走线（切片器会沿线拉直）。
**数值**：单边跨度 ≤15 mm 稳定，≤20 mm 需降温增速；两端各加 ≥1 mm 的锚固平台。
**失效模式**：一端悬空 = 悬臂，必然下垂；跨度中间有孔 = 桥接中断，两侧塌。

**替代**：把桥接改成 45° 斜坡（多花材料，但零风险），或拆件后粘接/螺钉。

---

## 5. 拆件与燕尾/榫槽

**何时用**：悬垂改不掉、超过构建体积、需要不同材料/颜色、需要后加工。

**怎么建**：沿"最不影响外观和强度"的平面切开；接缝做成 45° 燕尾或直榫 + 定位销。燕尾斜面与水平成 45–60° 时可免支撑。
**数值**：定位销 φ3–5，导入倒角 0.5×45°，配合间隙 0.15–0.25；燕尾深 ≥2 mm。
**失效模式**：直接平面对接 → 没有定位、错位、胶合强度全靠胶；接缝落在受拉侧 → 一拉就开。

---

## 6. 悬臂卡扣

**何时用**：需要反复拆装、又不想上螺钉。

**怎么建**：根部做 XY 平面圆角（受力平面内），自由端做 45° 导入斜面；卡扣厚度取线宽整数倍。
**数值**：厚度 1.2–2.0；允许应变 ε ≈ 3tδ/(2L²)，一次性装配 ≤2%（PETG）、反复使用 ≤0.7%；根部 R ≥ 0.5。
**失效模式**：根部直角 → 应力集中，第一次装就断；厚度不足 → 沿层裂；导入斜面缺失 → 装不进还硬掰。

**算例**：t=1.5、L=20、δ=1 → ε = 3×1.5×1/(2×400) = 0.56%，安全。

---

## 7. 活动铰（thin hinge）

**何时用**：盒盖、翻盖、一次性折叠结构。

**怎么建**：薄片的**厚度方向必须落在 XY 平面内**（薄片是一面竖墙），弯折时应力在层内而不是层间。
**数值**：厚 0.3–0.5，跨 0.4–0.6；PP/TPU 最好，PETG 可折几十次，PLA 基本一次就断。
**失效模式**：把薄片打成"平躺的薄板"（厚度方向 = Z），一折就沿层裂——这是最常见的错误。

---

## 8. 加强筋

**何时用**：大平面、悬臂、需要抗弯但不想加厚。

**怎么建**：筋厚取线宽整数倍；根部 XY 圆角；筋高 ≤3× 筋厚；间距 ≥2× 筋厚。
**数值**：筋厚 0.84 或 1.26；高厚比 ≤3；根部 R ≥ 0.5×筋厚。
**失效模式**：筋比壁还薄 → 只会打印出单圈线，不起加强作用；筋与壁等厚 → 交界处缩痕/空洞；筋太高 → 侧向失稳。

---

## 9. 螺柱与热熔螺母

**何时用**：需要可拆连接、且要反复拧。

**怎么建**：柱外径 ≥ 2× 孔径 + 2 圈壁；柱根做 0.5 mm 倒角/圆角；孔深 ≥1.5× 孔径，底部留 0.5 mm 不要打穿。
**数值**：M3 自攻：内孔 φ2.7，外径 ≥6.5；M3 热熔螺母：孔 φ4.0，深 5.7。
**失效模式**：外径太薄 → 拧的时候炸开；孔打穿 → 螺丝顶出、漏；无倒角 → 首层压扁导致螺母压不进。

---

## 10. 点阵/镂空

**何时用**：减重、缓冲、透气、装饰，或需要"看起来很复杂但不加成本"。

**怎么建**：只用 45° 菱形/八角桁架，禁止水平杆件；杆径取 2 圈以上。
**数值**：杆径 ≥0.84（推荐 1.2）；单元 4–8 mm；外壁保留 1.2 mm 实体壳。
**失效模式**：水平杆件悬空 → 全靠桥接，必塌；杆太细 → 一碰就断；点阵直接外露 → 强度低还藏污。

---

## 11. 底边倒角（大象脚的标准解）

**何时用**：所有需要精度或需要好拆的零件。

**怎么建**：底边做 0.5–1.0 mm × 45° 倒角，把首层压扁的鼓边"藏"进倒角里。
**数值**：0.5–1.0 mm；大件取 1.0，精细件取 0.5。
**失效模式**：底边直角 → 首层鼓边让零件装不进、放不平；倒角过大 → 牺牲首层接触面积、容易脱板。

> 注意：**大象脚是首层压扁 + 热积累造成的，不是"圆角造成的"**。倒角是解法，不是病因。

---

## 12. 文字、浮雕、标识

**何时用**：型号、刻度、方向标。

**怎么建**：文字放在**顶面或竖面**；竖面上的字是"沿 Z 拉伸的轮廓"，走线连续，最清晰。避免放在斜面上。
**数值**：字高 ≥4（推荐 6），笔画 ≥0.6，凹刻 ≥0.4 深；凹刻比浮雕清晰。
**失效模式**：字放在缓坡上 → 笔画被台阶切碎；笔画 <0.6 → 断笔；浮雕太高 → 碰掉。

---

## 13. 纯 Python 出网格（没有 CAD 时）

本工作区已有可复用的写法（`make_3mf.py`），要点：

1. **顶点去重**：按 4 位小数取整做键，避免裂缝。
2. **绕向一致**：外表面逆时针（右手法则朝外），所有壳统一。绕向错了体积为负、内外判定反。
3. **闭合**：每条边恰好被两个三角形共用；壳体不能相交。
4. **导出**：STL 二进制（80 字节头 + uint32 数量 + 50 字节/面）或 3MF（zip 包 + `[Content_Types].xml` + `_rels/.rels` + `3D/3dmodel.model`）。
5. **必检**：出网格后跑预检，不要靠切片器"看起来还行"。

```bash
python .dsh/skills/dfam-print-design/scripts/dfam_preflight.py stl/part.stl
```

## 14. 组合检查顺序（照这个顺序自查，不会漏）

1. 姿态定了吗？CAD 的 Z 就是打印的 Z 吗？
2. 主受力在 XY 面内吗？外壁够吗？
3. 每个 Z 向转折都是 45° 直平面吗？有没有偷偷留下的竖直圆弧？
4. 所有壁厚是线宽整数倍吗？
5. 每个 <45° 的下表面都改形了吗？改不掉的是不是该拆件？
6. 孔是泪滴/菱形吗？竖直孔补偿了吗？
7. 配合有间隙和导入倒角吗？底边有倒角吗？
8. 首层接触够吗？
9. 预检 PASS 了吗？
10. 风险声明写了吗？
