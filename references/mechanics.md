# 经典力学速查（承力件）

给"要算一个数"的时候用。每条都注明适用条件；条件不满足时，结论无效，改用有限元、试验或保守假设。

## 0. 五步流程

```
自由体图 → 载荷路径 → 内力（M/V/N/T）→ 危险截面 → 应力/变形 → 许用值 → 判据
```

- **载荷路径**：力从哪进、从哪出、经过哪些截面。最短路径通常最强；路径上突然变细的地方是危险截面。
- **危险截面**：M 最大、A 最小、Kt 最大、或三者叠加的位置。先找位置，再算数值。
- **支承条件决定一切**：固支与简支的弯矩差 4 倍，挠度差 16 倍。装配方式就是支承条件，别凭想象。

## 1. 单位（最容易出错的地方）

统一用 **N / mm / MPa**：`1 MPa = 1 N/mm²`，`E` 用 MPa，`I` 用 mm⁴，`δ` 用 mm，`σ` 用 MPa。
把 GPa 当 MPa、把 m 当 mm，是最常见的量级错误。**算完先做量纲与量级检查。**

## 2. 截面特性

| 截面 | A | I（弯曲） | J / 抗扭 |
|---|---|---|---|
| 矩形 b×h（绕平行 b 的轴） | b·h | b·h³/12 | 薄矩形近似：J ≈ b·h³·β，τ_max = T/(α·b·h²) |
| 圆 d | πd²/4 | πd⁴/64 | πd⁴/32 |
| 圆管 d_o, d_i | π(d_o²−d_i²)/4 | π(d_o⁴−d_i⁴)/64 | π(d_o⁴−d_i⁴)/32 |
| 薄壁圆管 r, t | 2πrt | ≈ πr³t | ≈ 2πr³t |
| 薄壁方管 a, t | ≈ 4at | ≈ (2/3)a³t | ≈ a³t |

弯曲截面模量 `S = I/c`，`c` 是到中性轴最远距离（矩形 c = h/2）。

**关键直觉**：`I ∝ h³`。把高度从 6 加到 8（+33%），刚度 +137%。**加高比加厚有效得多**，但要注意薄壁屈曲（见 §5）。

## 3. 梁（线弹性、小变形、等截面）

| 工况 | 最大弯矩 | 最大挠度 |
|---|---|---|
| 悬臂，端部集中力 F | M = F·L（根部） | δ = FL³/(3EI) |
| 悬臂，均布 w（N/mm） | M = wL²/2 | δ = wL⁴/(8EI) |
| 简支，中点集中力 F | M = FL/4 | δ = FL³/(48EI) |
| 简支，均布 w | M = wL²/8 | δ = 5wL⁴/(384EI) |

弯曲正应力 `σ = M·c/I`。中性轴处为零，表面最大。
**不要用叠加原理处理大变形、接触或塑性。**

## 4. 扭转与轴

`τ = T·r/J`，`θ = T·L/(G·J)`，`P = T·ω`（P 为功率，ω 为角速度 rad/s）。
圆轴最大剪应力在表面。非圆截面（方轴、六角）不能用 Tr/J，需查表或用 `τ_max = T/(α b h²)`。

**聚合物轴的经验**：扭转刚度常被低估，长径比大的轴要考虑扭转变形导致的失稳（尤其 PETG 会蠕变）。

## 5. 压杆与薄壁稳定性

**欧拉屈曲**：`P_cr = π²EI/(KL)²`

| 端部条件 | K |
|---|---|
| 两端铰支 | 1.0 |
| 一端固支一端自由 | 2.0 |
| 一端固支一端铰支 | 0.7 |
| 两端固支 | 0.5 |

**适用范围**：`λ = KL/r`（`r = √(I/A)`）必须大于 `λ_c = π√(E/σy)`；否则材料先屈服，欧拉公式高估承载力。

| 材料 | E (MPa) | σy (MPa) | λ_c |
|---|---|---|---|
| PLA | 3500 | 50 | ≈26 |
| PETG | 2000 | 48 | ≈20 |
| ABS | 2200 | 40 | ≈23 |
| PA | 1500 | 45 | ≈18 |
| PC | 2300 | 60 | ≈19 |

`λ < λ_c` 时按屈服 + 折减（经验取 `σ_cr ≈ σy·[1 − σy·λ²/(4π²E)]`，E1 级）。

**薄壁局部屈曲**（受压平板，四边简支）：`σ_cr = k·π²E/(12(1−ν²))·(t/b)²`，单轴压缩 k≈4。
例：PETG，t=1.2，b=40，ν=0.35 → σ_cr ≈ 6.8 MPa。**远低于屈服强度**——薄壁先鼓，不是先断。这是打印件加筋比加厚更有效的原因，也是"薄壁大平面"最容易踩的坑。

## 6. 应力集中

| 几何 | Kt（近似） |
|---|---|
| 无限宽板中央圆孔，单向拉伸 | 3.0 |
| 有限宽板圆孔（宽 w、孔 d） | 3 − 3.13(d/w) + 3.66(d/w)² − 1.53(d/w)³ |
| 台阶轴圆角（r/d ≈ 0.1，D/d ≈ 1.5） | 1.6–2.0 |
| 尖锐缺口 / 螺纹根部 | 2–4 |
| 打印件层间接缝 + 孔隙 | 在上值之上再叠加，实际更高 |

`σ_max = Kt · σ_nom`。**孔边、根部、截面突变三处必查。**
打印件的层间缺口敏感度高于本体，Kt 与各向异性叠加时，不能只按本体强度打折。

## 7. 连接

- **净截面拉伸**：`σ_net = F/((w−d)·t)`，峰值 `σ_max = Kt·σ_net`
- **孔边承压**：`σ_b = F/(d·t)`，聚合物许用承压强度通常 0.8–1.2×σy（E1，须实测）
- **边距**：`e ≥ 1.5d`；不足时按撕裂面积 `2·e·t` 校核剪切
- **螺栓预紧**：`F_i ≈ 0.7·σy·A_t`（金属）；聚合物件不要靠预紧力，靠热熔螺母或加大承压面
- **螺纹**：打印螺纹的剪切强度远低于机加工，M6 以下改用螺母/自攻/热熔嵌件

## 8. 卡扣

`ε = 1.5·t·δ/L²`（等截面悬臂，t 为根部厚度，δ 为挠度，L 为长度）

| 用途 | 允许应变（E1） |
|---|---|
| 一次性装配 | PETG ≤2%，ABS ≤1.5%，PA ≤3% |
| 反复拆装 | ≤0.7%，且按疲劳折减 |
| 长期保持 | ≤0.5%，考虑蠕变 |

根部做圆角（XY 平面内），沿层内弯曲；厚度取线宽整数倍只是次要约束。

## 9. 安全系数

| 工况 | SF | 说明 |
|---|---|---|
| 静载、载荷确定、有 E3 数据 | 1.5–2.0 | 下限仅用于载荷非常明确时 |
| 静载、载荷不确定 | 2.0–3.0 | 打印件默认落在这里 |
| 循环载荷 | 2.0–4.0 | 必须另做疲劳评估，不能只乘系数 |
| 冲击/跌落 | 3.0–5.0 | 打印件缺口敏感，取上限 |
| 人身安全相关 | ≥5 或拒接 | 需 E3/E4 证据，否则明说不能保证 |

**许用值必须是"打印件"的，不是 filament datasheet 的。** datasheet 是注塑试样，通常高估 30–100%。

## 10. 温度与蠕变

- 使用温度接近 `Tg` 时，聚合物在持续载荷下会缓慢变形并失效，**强度校核通过也会坏**。
- 经验门槛：`T_use > Tg − 30°C` 时按蠕变评估。

| 材料 | Tg（近似） | 建议长期承载温度上限（E1） |
|---|---|---|
| PLA | 55–60 °C | ≤30 °C |
| PETG | 78–82 °C | ≤50 °C |
| ABS | 100–105 °C | ≤70 °C |
| ASA | 100–105 °C | ≤75 °C |
| PA | 60–80 °C（干态偏高） | ≤50 °C |
| PC | 145 °C | ≤100 °C |

长期承载时，许用应力进一步折减到 `0.4–0.5 × σ_allow`（E1）。

## 11. 四个算例（可复核）

### 例 1：悬臂梁 + 打印方向

PETG，截面 b=20、h=6，L=60，端部 F=50 N。

```
I = 20·6³/12 = 360 mm⁴        c = 3 mm
σ = F·L·c/I = 50·60·3/360 = 25 MPa
δ = F·L³/(3EI) = 50·216000/(3·2000·360) = 5.0 mm
```

- 若 **h 沿 Z**（零件竖着打）：弯曲正应力是层间方向，PETG 层间许用约 15–20 MPa → **25 MPa 不合格**。
- 若 **h 在 XY**（躺着打）：许用约 40–45 MPa → 合格，δ 同样是 5.0 mm（刚度与方向关系较小，强度关系很大）。

结论：**同一几何，换姿态就把"不合格"变成"合格"**。先定姿态再定截面，顺序不能反。

### 例 2：细长压杆

PA，实心圆柱 d=8，L=120，两端铰支（K=1）。

```
A = 50.3 mm²      I = 201 mm⁴      r = √(I/A) = 2.0 mm
λ = KL/r = 60     λ_c = π√(1500/45) ≈ 18 → 欧拉适用
P_cr = π²·1500·201/120² ≈ 207 N
```

取 SF=2.5 → 允许 83 N。若只看"截面积 × 屈服"会得到 2260 N，**高估 11 倍**——这就是为什么压杆必须先查稳定性。

### 例 3：卡扣应变

t=1.5，L=20，装配挠度 δ=1.0。

```
ε = 1.5·t·δ/L² = 1.5·1.5·1.0/400 = 0.56%
```

反复拆装（≤0.7%）合格；一次性（≤2%）有大量余量。若 δ 增到 2.0 → ε=1.1%，超过反复使用限值。

### 例 4：孔边

板 w=30，t=4，d=8，拉伸 F=400 N，孔在板中。

```
d/w = 0.267 → Kt = 3 − 0.836 + 0.260 − 0.029 ≈ 2.40
A_net = (30−8)·4 = 88 mm²
σ_net = 4.55 MPa → σ_peak ≈ 10.9 MPa
承压 σ_b = 400/(8·4) = 12.5 MPa      边距 e ≥ 12 mm
```

若载荷沿 Z（层间），10.9 MPa 已接近 PETG 层间许用值，必须改姿态或加宽净截面。

## 12. 常见误用

| 误用 | 后果 |
|---|---|
| 用 filament datasheet 的 σu 当许用值 | 高估 30–100%，实际提前断裂 |
| 忘了 Kt | 孔边/根部低估 2–3 倍 |
| 把 Euler 用到 λ < λ_c | 高估压杆承载力 |
| 用"填充率"推断强度 | 强度由外壁与走线决定，与填充率非线性 |
| 假设各向同性 | Z 向先失效，且缺口处更严重 |
| 单位混用（GPa/MPa、m/mm） | 量级错 1000 倍 |
| 用静强度乘系数代替疲劳评估 | 循环载荷下寿命完全不可控 |
| 忽略蠕变 | 常温长期受载缓慢变形，装配失效 |

## 13. 没有数据时怎么做

1. 明确写出假设："PETG 层间许用取 18 MPa，来源：E1 经验区间，未实测"。
2. 用保守端取值，并把 SF 提到区间上限。
3. 给出验证计划：同工艺同方向试件 5 件，测拉伸/弯曲，得到 E3。
4. 输出写 **"初步设计，待验证"**，列出待验证项与验收标准。

**不要用精确到小数点后两位的数字，去掩盖一个 E1 级的假设。**
