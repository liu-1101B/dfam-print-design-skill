# 评测集

用来回答一个问题：**改了技能之后，AI 的判断是变好了还是变差了？**

不以"回答流畅"为通过标准，只以四件事为标准：

1. 物理判断正确（失效模式找对了吗）
2. 计算可复核（数字能自己算一遍）
3. 假设透明（已知/假设/待验证分开了吗）
4. 风险没有被掩盖（有没有把 E1 说成"安全"）

## 结构

```
evals/
├── README.md          本文件：协议、评分、禁止结论
└── cases/
    ├── 01-cantilever-beam.md      弯曲应力 + 挠度 + 打印方向
    ├── 02-slender-column.md       屈曲，不能只看强度
    ├── 03-bolted-plate.md         净截面、孔边承压、应力集中
    ├── 04-snap-fit.md             弯曲应变、装配变形、疲劳
    ├── 05-shaft-and-bushing.md    转动间隙 vs 压配 vs 打印误差
    ├── 06-large-thin-shell.md     翘曲、刚度、局部失稳
    ├── 07-overhang-part.md        姿态 / 几何 / 支撑三方案比较
    └── 08-missing-data.md         缺数据时不得虚构强度与安全系数
```

## 怎么用

1. 新开一个会话，让 AI 加载本技能，然后**只给场景，不给提示**。
2. 逐条对照"期望判断"（必须出现）、"禁止出现的结论"（出现即不通过）。
3. 数值用"参考答案"核对，允许 5% 计算误差，不允许方向性错误（高估/低估一个数量级）。
4. 记录分数，改技能前后各跑一遍，比较差异。

本机实测一条命令即可（几何类案例）：

```bash
python scripts/dfam_preflight.py <案例网格>
```

## 评分（每维 0–2 分，共 7 维）

| 维度 | 0 分 | 2 分 |
|---|---|---|
| 失效模式识别 | 直接给几何建议 | 先指出会怎么坏，再给方案 |
| 计算正确性 | 没有数或算错 | 公式、代入、单位、结果都对 |
| 方向处理 | 当各向同性 | 区分 XY/Z 并说明许用值来源 |
| 假设透明 | 假设写成事实 | 已知/假设/待验证分开列 |
| 证据等级 | 宣称"安全" | 标注 E0–E4，未达 E3 写"待验证" |
| 可制造性 | 只谈力学 | 给姿态、特征、公差的可执行值 |
| 冲突取舍 | 只堆规则 | 说明为什么选 A 不选 B |

**通过线**：≥11/14，且**没有**任何禁止结论。

## 全局禁止结论（任何案例出现即不通过）

- "已经安全 / 完全可以承受 / 不会有问题"
- 用 filament datasheet 的强度当打印件许用值
- 只按 `F/A` 判断承力件（漏掉弯曲、屈曲、Kt、承压）
- 把 `dfam_preflight.py` 的 PASS 当作强度通过
- 给出精确到小数点后两位、但来源是猜测的强度值
- 在缺载荷/缺材料数据时给出确定结论
- 把"初步设计，待验证"省略掉

## 维护约定

- 新增案例必须带**可复核的数字**，否则只能是定性检查，价值低。
- 修改技能后如果案例大面积失败，先怀疑技能，不要先改案例。
- 案例之间不要重复同一种失效模式。
