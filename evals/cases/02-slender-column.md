# 案例 02 · 细长压杆

**场景**

PA（尼龙）打印的支柱：实心圆柱 φ8、长 120 mm，两端铰支，承受 150 N 轴向压力。用户问："直径 8 mm 够不够？"

## 期望判断（必须出现）

1. 识别失效模式是**屈曲**，不是屈服。
2. 算长细比并判断欧拉公式是否适用：λ = 60，λ_c ≈ 18 → 适用。
3. 算临界载荷 P_cr ≈ 207 N，得安全系数 ≈ 1.38，**低于常规 2.5**，结论不合格。
4. 指出如果错用屈服判据（A·σy ≈ 2260 N）会**高估约 11 倍**。
5. 给改进并算数：d 加到 10 → P_cr ≈ 505 N（SF≈3.4）；或自由长度缩到 80 → P_cr ≈ 465 N。
6. 说明端部条件（铰支 K=1）来自实际装配，若改成固支 K=0.7，P_cr 提高 (1/0.7)²≈2 倍，但要有真实约束。

## 必须检查的约束

- 端部条件与 K 值来源
- 长细比是否超过 λ_c（否则欧拉不适用）
- 是否为打印件的 Z 向受压（层间压缩通常好于拉伸，但薄壁柱会提前失稳）
- 初始缺陷/直线度（打印件有波纹，会降低实际 P_cr）

## 参考答案（可复核）

```
A = π·8²/4 = 50.3 mm²        I = π·8⁴/64 = 201 mm⁴
r = √(I/A) = 2.0 mm          λ = KL/r = 1·120/2 = 60
λ_c = π√(E/σy) = π√(1500/45) ≈ 18  →  λ > λ_c，欧拉适用
P_cr = π²·1500·201/120² ≈ 207 N
SF = 207/150 ≈ 1.38  → 不合格（常规要求 2.5）

改 d=10：I = 490.9 mm⁴ → P_cr = π²·1500·490.9/120² ≈ 505 N，SF ≈ 3.4
改 L=80：P_cr = π²·1500·201/80² ≈ 465 N，SF ≈ 3.1
```

## 禁止出现的结论

- 「截面积乘屈服强度 = 2260 N，够用」。
- 不查长细比就套欧拉公式。
- 用"PA 抗压强度高"作为结论。
- 忽略端部条件，或凭空假设固支以提高承载力。
