# 案例 04 · 卡扣结构

**场景**

PETG 盖子上的悬臂卡扣：根部厚 1.5 mm、长 20 mm，装配时需要挠度 2.0 mm，要求能反复拆装 100 次以上。用户问："这个卡扣行不行？"

## 期望判断（必须出现）

1. 用卡扣应变公式：ε = 1.5·t·δ/L² = 1.5×1.5×2.0/400 = **1.125%**。
2. 对照许用：一次性 ≤2%，反复使用 ≤0.7%（E1）→ **1.125% 超过反复使用限值，不合格**。
3. 给至少两个改进方案并算数：
   - 加长到 L=28：ε = 0.574% ✓
   - 或减小挠度到 δ=1.2：ε = 0.675% ✓
4. 指出**疲劳**要单独验证：100 次已属低周，但打印件层间缺陷会显著降低寿命，需做装配循环试验。
5. 指出根部要圆角（按应力集中，不是按打印规则），钩部要有 30–45° 导入斜角。
6. 标注 E1 + "初步设计，待验证"。

## 必须检查的约束

- 区分"一次性装配"与"反复拆装"的许用应变
- 卡扣根部是否落在层间（若根部沿 Z 生长，寿命更差）
- 长期保持力会因蠕变下降
- 挠度 δ 是装配总挠度，不是单边间隙

## 参考答案（可复核）

```
ε = 1.5·t·δ/L² = 1.5·1.5·2.0/20² = 0.01125 = 1.125%
反复拆装许用 ≈ 0.7%  →  超限 60%

改 L=28：ε = 1.5·1.5·2.0/784 = 0.574%  ✓
改 δ=1.2：ε = 1.5·1.5·1.2/400 = 0.675%  ✓
改 t=1.0：ε = 1.5·1.0·2.0/400 = 0.75%   （临界，且根更弱）
```

## 禁止出现的结论

- 「加个圆角就好了」——圆角降低应力集中，但不改变整体弯曲应变。
- 用静强度判断卡扣"很结实"。
- 不区分一次性与反复使用。
- 认为 100 次"次数很少，肯定没问题"（层间缺口会显著折减）。
