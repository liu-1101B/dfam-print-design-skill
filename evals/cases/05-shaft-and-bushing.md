# 案例 05 · 转轴与轴套

**场景**

FDM / PETG，φ10 轴插入 φ10 孔，做手动旋转副（每周转几次，低转速），要求"能自由转动、不旷"。用户问："尺寸给多少？"

## 期望判断（必须出现）

1. 指出**名义等径 = 零间隙**，必然装不进或咬死；必须给间隙。
2. 区分三种配合，不能混为一谈：
   - 转动/滑动：直径间隙 **0.3–0.5 mm**（初始试制值）
   - 压配：过盈 **0.05–0.2 mm**
   - 定位销：介于两者之间
3. 指出**打印误差**会吃掉名义公差：竖直孔普遍偏小 0.1–0.2 mm；底部有**大象脚**鼓边；长孔有锥度；收缩造成椭圆。
4. 明确这些数字是**初始试制值**，必须用**校准试片**确定：打 5 档孔径（如 φ10.2 / 10.3 / 10.4 / 10.5 / 10.6），与 φ10 轴配对，选手感与旷量都合格的那档。
5. 给可执行的初始方案：轴 φ9.9、孔 φ10.3（直径间隙 0.4），孔底 0.5×45° 倒角，孔口加 0.5 导入斜角。
6. 说明验证：测**启动力矩**与**径向旷量**，并做 100 次转动后的磨损检查。

## 必须检查的约束

- 间隙是**直径**还是**半径**（差 2 倍，极易混淆）
- 长径比（长孔更难保证圆柱度）
- 表面质量（层纹会改变实际配合）
- 温度（PETG 在 50 °C 以上会变软，转动副可能抱死）

## 参考答案（可复核）

```
初始方案：轴 φ9.9，孔 φ10.3  → 直径间隙 0.4 mm
孔口倒角 0.5×45°，底部倒角 0.5×45°（治大象脚）
校准试片：孔径 10.2 / 10.3 / 10.4 / 10.5 / 10.6，各 1 件，同批同参数
判定：手转无卡滞、径向旷量 ≤0.15 mm 的那一档
```

## 禁止出现的结论

- 直接给「φ10.15」这类精确但无来源的值，且不说明需校准。
- 把压配过盈与转动间隙混为一谈。
- 忽略大象脚与孔口收缩，认为"标称 10 就是 10"。
- 声称"这样设计就能自由转动"而不给校准与验证方法。
