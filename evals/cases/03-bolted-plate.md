# 案例 03 · 带孔连接件

**场景**

PETG 板：宽 30 mm、厚 4 mm，中间一个 φ8 通孔，用销钉传递 400 N 拉力。孔轴垂直于板面（沿厚度方向）。用户问："孔够不够？"

## 期望判断（必须出现）

1. 识别**三处**可能失效：净截面断裂、孔壁承压、边距不足撕裂。
2. 算净截面应力：σ_net = F/((w−d)t) = 400/(22×4) ≈ 4.55 MPa。
3. 算应力集中：d/w = 0.267 → Kt ≈ 2.40 → 峰值 ≈ 10.9 MPa。
4. 算承压：σ_b = F/(d·t) = 400/32 = 12.5 MPa。
5. 检查边距：e ≥ 1.5d = 12 mm，否则按 2et 算撕裂。
6. 指出方向问题：若拉力沿 Z（层间），10.9 MPa 已接近 PETG 层间许用（15–20 MPa，E1），且缺口敏感性更高 → 必须改姿态或加宽净截面。
7. 标注 E1 + "初步设计，待验证"。

## 必须检查的约束

- 净截面是否只扣一个孔（多孔一排时要扣全部）
- Kt 适用于弹性、均质、单向拉伸；层间方向不能直接套本体 Kt
- 承压强度不是拉伸强度（聚合物约为 0.8–1.2×σy，E1）
- 孔轴方向与打印层向的关系

## 参考答案（可复核）

```
A_net = (30−8)·4 = 88 mm²
σ_net = 400/88 = 4.55 MPa
d/w = 0.267 → Kt = 3 − 3.13(0.267) + 3.66(0.267²) − 1.53(0.267³) ≈ 2.40
σ_peak = 4.55 × 2.40 ≈ 10.9 MPa
σ_bearing = 400/(8·4) = 12.5 MPa
边距 e ≥ 1.5d = 12 mm
```

## 禁止出现的结论

- 只算 `σ = 400/(30×4) = 3.3 MPa` 就判合格（漏掉净截面与 Kt）。
- 用 10.9 MPa 直接对比本体拉伸强度 50 MPa，结论"余量很大"。
- 不提承压与边距。
- 认为"孔不大，没关系"。
