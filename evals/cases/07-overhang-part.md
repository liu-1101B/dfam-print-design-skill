# 案例 07 · 复杂悬垂件（三方案比较）

**场景**

PETG L 形支架：底板 200 × 120 × 6，立板高 80，立板与底板之间有一条与水平成 30° 的加强肋。底板背面是**安装面**（要求平面度），立板上两个 φ6 孔是**配合面**（要求位置精度）。用户问："怎么打？"

## 期望判断（必须出现）

1. **先列硬约束**，不是先算支撑：
   - 安装面平面度 → 该面应贴床或朝上
   - φ6 孔位置精度 → 孔应竖直（沿 Z）打印，避免水平孔塌陷
   - 成形空间 200 × 120 × 80
   - 不得让支撑接触安装面与孔
2. **列三个方案并逐项比较**（不能只给一个）：
   - A 底板贴床（安装面朝下）：平面度最好、孔可竖直；但立板与 30° 肋成为悬垂 → 需支撑，且支撑接触立板外表面。
   - B 立板贴床：支撑接触安装面 → **违反硬约束，剔除**。
   - C 改几何：把 30° 肋改成 45°，悬垂消除；不改姿态，代价是肋变短/变厚，质量略增。
3. 说明**为什么选**：A 与 C 都可行；若外观要求高选 C（免支撑），若尺寸优先选 A（支撑只碰非功能面）。给出取舍依据而不是"最优解"。
4. 明确 `dfam_preflight.py` 只能给几何指标（支撑率/首层/天花板），**不能判断平面度与孔位精度**，这两项要在 CAD/切片里另行确认。

## 必须检查的约束

- 硬约束优先于支撑量：B 方案支撑率可能最低，但必须剔除
- 30° 肋在 A 方案下是 <45° 悬垂
- 肋改成 45° 后的长度变化与结构影响（肋高固定时，45° 更短）
- 支撑接触面是否可接受（外观/精度）

## 参考答案（定性 + 几何）

```
硬约束：
  1) 安装面平面度 → 不接触支撑
  2) φ6 孔位置精度 → 孔轴沿 Z
  3) 成形空间 200×120×80

方案 A（底板贴床）：满足 1)、2)；立板外表面 + 30° 肋需支撑
方案 B（立板贴床）：支撑压安装面 → 违反 1)，剔除
方案 C（30° 肋改 45°）：满足 1)、2)，免支撑；肋长缩短 ~30%，需复核肋的加强效果
```

## 禁止出现的结论

- 只报"支撑率最低的姿态"，不检查它是否压住安装面。
- 直接说"加支撑就行"，不比较改几何。
- 声称预检脚本已经验证了平面度或孔位精度。
- 给出单一"最优姿态"而不说明取舍。
