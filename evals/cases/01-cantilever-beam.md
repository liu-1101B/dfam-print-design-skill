# 案例 01 · 悬臂梁承载

**场景**

一个室内灯架：PETG 打印，悬臂长 60 mm，矩形截面宽 20 mm、高 6 mm，端部挂 3 kg 灯（≈50 N），室温、长期静载。用户问："这个能撑住吗？"

## 期望判断（必须出现）

1. 先识别失效模式：**弯曲正应力**（根部）与**挠度**，不是简单的拉伸。
2. 算出两个数：σ ≈ 25 MPa（根部），δ ≈ 5.0 mm。
3. 指出**打印方向决定成败**：高 h 沿 Z 时，弯曲正应力是层间方向，PETG 层间许用约 15–20 MPa（E1）→ 25 MPa **不合格**；h 在 XY 时，许用约 40–45 MPa → 合格。
4. 指出长期静载要按**蠕变**再折减（0.4–0.5×），室温 PETG 长期承载建议 ≤50 °C、长期应力再降。
5. 给出至少一个改进方案并算数，例如 h 从 6 加到 8：σ ≈ 14.1 MPa、δ ≈ 2.1 mm。
6. 标注证据等级 E1，写 **"初步设计，待验证"**，给验证计划（同方向弯曲试件）。

## 必须检查的约束

- 层间许用值来源（E1，非 datasheet）
- 端部载荷是集中力，不是均布
- 挠度 5 mm 是否可接受（用户没给位移上限 → 必须问，或明确假设）
- 长期载荷下的蠕变

## 参考答案（可复核）

```
I = 20·6³/12 = 360 mm⁴        c = 3 mm
σ = F·L·c/I = 50·60·3/360 = 25 MPa
δ = F·L³/(3EI) = 50·216000/(3·2000·360) = 5.0 mm

改进 h=8：I = 20·8³/12 = 853.3 mm⁴
σ = 50·60·4/853.3 = 14.1 MPa
δ = 50·216000/(3·2000·853.3) = 2.1 mm
```

## 禁止出现的结论

- 用 PLA/PETG datasheet 的 50 MPa 当许用值，结论"安全"。
- 只算 σ 不算 δ，或只说"太薄了，加厚"。
- 不区分 h 沿 Z 还是沿 XY，直接给"合格/不合格"。
- 给出"能撑住"的结论而不标证据等级。
